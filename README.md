# Sweet_Byte
### SOEN 343 Project 
## Overview 
**SweetByte** is an online dessert ordering and delivery platform that connects customers with local restaurants and couriers. The platform allows customers to browse menus, place orders, and pay for their meals, restaurants to manage their menus and orders, couriers to handle deliveries, and operators to oversee and manage overall platform activity.

*Note: This project was built in the context of an academic project for the course SOEN 343 at Concordia University and is not intended for commercial use.*


## Technologies
- **Frontend Language** - JavaScript or Typescript
- **Frontend Framework** - Next.js
- **Backend Language** - Java
- **Backend Framework** - Spring boot
- **Database** - Firebase database (PostgreSQL)
- **Authentication** - Firebase Authentication
